The production weekend picker was merged on 13 October, after the most recent
`data-latest` release was built on 12 October. That release's provider metadata
is build version 3; its line tiles lack `service_days`. The picker deliberately
passes missing masks, so it cannot filter that release. Main's builder is
version 4 and emits `service_days`; this branch bumps it to version 5 so the
verified facts rebuild even if a version 4 dataset is published first. A new
Data workflow run after these corrections are merged is required for
production to use the filter and labels.
